# Overfit and Chill — overfitandchill.co.za

Personal analytics blog built with [Quarto](https://quarto.org) + [Hugo](https://gohugo.io) + [Blonde theme](https://github.com/opera7133/Blonde), hosted on GitHub Pages at [overfitandchill.co.za](https://overfitandchill.co.za).

---

## Tech Stack

| Tool | Purpose |
|---|---|
| Quarto | Executes R and Python code, renders `.qmd` files to Hugo markdown |
| Hugo Extended | Builds the final HTML site from markdown |
| Blonde Theme | Site theme (TailwindCSS-based dark/light mode) |
| GitHub Actions | Auto-builds and deploys on every push to `main` |
| GitHub Pages | Hosts the built site from the `/docs` folder |
| Afrihost DNS | Points `overfitandchill.co.za` to GitHub Pages |

## Creating a New Post — Step by Step

### Step 1 — Create the Post Folder

Navigate to your project folder and create a new folder under `content\posts\`:

```bash
cd "C:\Users\user pc\Desktop\my-hugo-website"
mkdir content\posts\your-post-name
```

Replace `your-post-name` with a short kebab-case name e.g. `sa-inflation-tracker`.

---

### Step 2 — Create the Post File

Create `content\posts\your-post-name\index.qmd` and add this front matter at the top:

```yaml
---
title: "Your Post Title"
date: 2026-01-01
draft: false
summary: "One or two sentences shown on the home page card. Plain language, no jargon."
description: "Same or similar to summary — used for SEO meta tags."
categories: [R, Finance, South Africa]
image: /posts/your-post-name/thumbnail.JPG
execute:
  freeze: auto
---
```

**Front matter field reference:**

| Field | Notes |
|---|---|
| `title` | Shown as the post heading and on the home page card |
| `date` | Fixed date in `YYYY-MM-DD` format — never use `today` |
| `draft: false` | Must be `false` for the post to appear on the site |
| `summary` | Shown on the home page listing card |
| `description` | Used for SEO — can match `summary` |
| `categories` | List of tags shown in the sidebar and used for filtering |
| `image` | Absolute path starting with `/posts/your-post-name/` |
| `execute: freeze: auto` | Only re-runs code if the source file changes |
| `execute: freeze: true` | Never re-runs code — use for posts with heavy dependencies (Python ML, Julia) |

---

### Step 3 — Add a Thumbnail

Add a thumbnail image to the post folder:
```
content\posts\your-post-name\thumbnail.JPG
```

Recommended size: **800 × 450px** (16:9 ratio works best for the card layout).

Also copy it to the static folder so Hugo can serve it:
```bash
mkdir static\posts\your-post-name
copy content\posts\your-post-name\thumbnail.JPG static\posts\your-post-name\thumbnail.JPG /Y
```

---

### Step 4 — Write the Post Content

Write your analysis below the `---` front matter block using standard Quarto markdown.

**R code chunk:**
````
```{r}
#| label: my-plot
#| fig-cap: "My chart caption"
#| message: false

library(ggplot2)
# your R code here
```
````

**Python code chunk:**
````
```{python}
import pandas as pd
# your Python code here
```
````

**Display math (LaTeX):**
```
$$
y = \beta_0 + \beta_1 x + \varepsilon
$$
```

**Inline math:**
```
The coefficient $\beta_1$ represents the slope.
```

### Step 5 — Preview Locally

Start the Hugo preview server:

```bash
cd "C:\Users\user pc\Desktop\my-hugo-website"
hugo server
```

Open `http://localhost:1313` in your browser. The site live-reloads when you save files.

To also run Quarto to execute your R/Python code and see the rendered output:

```bash
"C:\Program Files\RStudio\resources\app\bin\quarto\bin\quarto.exe" render content\posts\your-post-name\index.qmd
```

Then refresh your browser.

---

### Step 6 — Copy Generated Files to Static

After Quarto renders the post, copy any generated files to the `static/` folder so Hugo can serve them.

**For posts with data files (JSON, CSV):**
```bash
xcopy content\posts\your-post-name\data static\posts\your-post-name\data /E /I /Y
```

**For posts with OJS interactive widgets** (posts using `ojs` code chunks):
```bash
xcopy content\posts\your-post-name\index_files static\posts\your-post-name\index_files /E /I /Y
```

**For posts with pre-rendered figures:**
```bash
xcopy content\posts\your-post-name\figures static\posts\your-post-name\figures /E /I /Y
```

**Always copy the thumbnail:**
```bash
copy content\posts\your-post-name\thumbnail.JPG static\posts\your-post-name\thumbnail.JPG /Y
```

### Step 7 — Commit and Push

Once you are happy with how the post looks locally:

```bash
cd "C:\Users\user pc\Desktop\my-hugo-website"
git add .
git commit -m "add new post: your post title"
git push
```

If the push is rejected because GitHub Actions committed a build:

```bash
git pull origin main --rebase
git push
```

GitHub Actions will automatically build and deploy the site. Watch the progress at:
```
https://github.com/rossouwvanjaarsveld-lang/hugo-website/actions
```

The site will update at `https://overfitandchill.co.za` within 2–3 minutes of the workflow going green.

## Post Types Reference

### R-only post (ggplot2 charts)

- Set `execute: freeze: auto`
- No data files needed in static unless you load external JSON/CSV
- No OJS runtime files needed

### Python-only post (Plotly charts)

- Set `execute: freeze: auto`
- Make sure `jupyter` is installed: `py -m pip install jupyter`
- No extra static files needed

### Interactive OJS post (widgets, dropdowns, reactive charts)

- After rendering, run: `xcopy content\posts\your-post-name\index_files static\posts\your-post-name\index_files /E /I /Y`
- If data is loaded via `ojs_define()` from R, replace with `fetch()` calls in OJS pointing to `/posts/your-post-name/data/filename.json`
- Copy data files: `xcopy content\posts\your-post-name\data static\posts\your-post-name\data /E /I /Y`

### Julia or heavy ML post (freeze: true)

- Set `execute: freeze: true` — Quarto will NOT re-run the code
- Pre-render figures must already exist in the `figures/` folder
- Copy figures: `xcopy content\posts\your-post-name\figures static\posts\your-post-name\figures /E /I /Y`

## Updating an Existing Post

1. Edit the `index.qmd` file
2. If you changed R/Python code: re-render with Quarto and copy updated static files
3. If you only changed text/markdown: skip the render step
4. Push as normal:

```bash
git add .
git commit -m "update post: your post title"
git push
git pull origin main --rebase
git push
```

## Updating the ETF Tracker Data

The ETF tracker post has an automated pipeline. Double-click:

```
update_and_render.bat
```

This script:
1. Runs `scrape_etfs.R` to fetch fresh data from Yahoo Finance and Just One Lap
2. Copies updated JSON files to `static/posts/ee-etf-tracker/data/`
3. Re-renders the post with Quarto
4. Copies the OJS runtime files to static
5. Copies the thumbnail to static

After the script finishes, push normally:

```bash
git add .
git commit -m "update etf data"
git push
git pull origin main --rebase
git push
```

## Common Errors and Fixes

### Push rejected (fetch first)
```bash
git pull origin main --rebase
git push
```

### Quarto not recognised
Use the full path:
```bash
"C:\Program Files\RStudio\resources\app\bin\quarto\bin\quarto.exe" render content\posts\your-post-name\index.qmd
```

### OJS widgets not working (data not loading)
Make sure data files are in `static\posts\your-post-name\data\` and that OJS uses `fetch('/posts/your-post-name/data/filename.json')` not `ojs_define()`.

### Math not rendering
Display math must use `$$...$$` delimiters on their own lines. Inline math uses `$...$`. KaTeX is loaded site-wide via `layouts\partials\head.html`.

### Thumbnail not showing
Make sure the image is in `static\posts\your-post-name\` and the front matter uses an absolute path: `image: /posts/your-post-name/thumbnail.JPG`.

### GitHub Actions failing
Go to `https://github.com/rossouwvanjaarsveld-lang/hugo-website/actions`, click the failed run, expand the red step, and read the error. Common causes: missing R package (add to workflow's `packages:` list), missing Python package (add to `pip install` line), or a code error in the post.

## Deployment Pipeline Summary

```
You edit index.qmd
       ↓
quarto render  (executes R/Python, outputs index.md)
       ↓
git push
       ↓
GitHub Actions (installs Hugo + TailwindCSS, runs hugo --minify)
       ↓
Hugo builds /docs folder
       ↓
Actions commits /docs back to main
       ↓
GitHub Pages serves /docs
       ↓
overfitandchill.co.za (via Afrihost DNS → GitHub Pages IPs)
```
